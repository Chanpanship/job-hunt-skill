# Contributing

Thanks for helping improve job-hunt-skill.

Good contributions include official API/RSS job-source support, reproducible
ATS guidance, Computer Use recovery improvements, and clear bug reports.

Before opening a pull request:

- Keep real resumes, contact details, credentials, application answers, and
  `workspace` records out of commits.
- Never add fabricated credentials, metrics, or job history to examples.
- Preserve the rules against credential handling, CAPTCHA bypass, and unresolved
  legal attestations.
- Run `git diff --check` and relevant Python checks.
